### Track 2: Query Refactoring & Verification (Assigned to: Shirsh)

4. **Crucial Rule:** Results of rewritten queries must be **100% identical** (same row count, same columns, same values). Test with `EXCEPT` checksum queries.

#### Crucial Rewrites Needed:

##### 1. Fix R13 (The NULL Bug — Worth 2 Marks)
- **Problem:** `WHERE learner_id NOT IN (SELECT referred_by FROM learners)` returns **0 rows** because `referred_by` contains 21,102 NULLs. In SQL three-valued logic, `x NOT IN (..., NULL)` evaluates to `UNKNOWN`, filtering out every learner.
- **Optimized Rewrite:**
  ```sql
  -- @R13
  -- Referral programme: learners who have not referred anyone yet (Fixed NULL bug)
  SELECT l.learner_id, l.username
  FROM learners l
  WHERE NOT EXISTS (
      SELECT 1 FROM learners r WHERE r.referred_by = l.learner_id
  );
  ```

##### 2. Rewrite R19 (The ~1.44 Second Bottleneck — Target: < 10 ms)
- **Problem:** Two correlated subqueries inside `SELECT` re-scan `lesson_attempts` 160 times.
- **Optimized Rewrite (Aggregate attempts in a CTE or JOIN first):**
  ```sql
  -- @R19
  -- Curriculum report: completions and average mistakes of every lesson in the Spanish course
  WITH attempt_stats AS (
      SELECT a.lesson_id,
             count(*) FILTER (WHERE a.completed_at IS NOT NULL) AS completions,
             round(avg(a.mistakes), 2) AS avg_mistakes
      FROM lesson_attempts a
      GROUP BY a.lesson_id
  )
  SELECT l.lesson_id, u.unit_no, l.lesson_no,
         coalesce(s.completions, 0) AS completions,
         s.avg_mistakes
  FROM lessons l
  JOIN units u ON u.unit_id = l.unit_id
  LEFT JOIN attempt_stats s ON s.lesson_id = l.lesson_id
  WHERE u.course_id = 1
  ORDER BY u.unit_no, l.lesson_no;
  ```

##### 3. Rewrite R04 (Sargable Date Range)
- **Problem:** `DATE(a.started_at) = '2026-06-30'` cannot use a standard index on `started_at` without an expression index.
- **Optimized Rewrite:**
  ```sql
  -- @R04
  -- Daily goal ring: XP learner 1042 earned on 30 June 2026 vs their daily goal
  SELECT l.daily_goal_xp, coalesce(sum(a.xp_earned), 0) AS xp_today
  FROM learners l
  LEFT JOIN lesson_attempts a 
    ON a.learner_id = l.learner_id 
   AND a.started_at >= '2026-06-30 00:00:00+05:30' 
   AND a.started_at < '2026-07-01 00:00:00+05:30'
  WHERE l.learner_id = 1042
  GROUP BY l.daily_goal_xp;
  ```

##### 4. Rewrite R20 (Sargable Date Grouping)
- **Problem:** `started_at::date BETWEEN ...` disables index scans.
- **Optimized Rewrite:** Use `started_at >= '2026-06-01 00:00:00+05:30' AND started_at < '2026-07-01 00:00:00+05:30'`.

##### 5. Proof of Unchanged Results
Run checksum / `EXCEPT` validation:
```sql
-- Original query EXCEPT Optimized query must return 0 rows!
(SELECT ... [original]) EXCEPT (SELECT ... [optimized]);
(SELECT ... [optimized]) EXCEPT (SELECT ... [original]);
```
